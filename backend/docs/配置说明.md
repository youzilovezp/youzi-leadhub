# Leadhub 后端配置说明

> 所有配置项都在 `app/core/config.py` 中定义，通过 pydantic-settings 从 `.env` 文件加载。
> 普通用户**不需要改任何字段**：密码在 `.env`（已自动生成），数据库 UI 地址 http://localhost:8080（make start 后）。

## 配置文件加载优先级

1. 环境变量（最高）
2. `.env` 文件
3. `Settings` 类中的默认值（最低）

## 启动后会自动设置的项

| 项 | 值 | 说明 |
|---|---|---|
| `SECRET_KEY` | 随机生成 64 位 hex | init.py 自动写入 .env |
| `POSTGRES_PASSWORD` | 随机生成 20 位 | init.py 自动写入 .env |
| 其它中间件密码 | 随机生成 | init.py 自动写入 .env |

## 常用配置项

### 应用基础

| 变量 | 默认值 | 说明 |
|---|---|---|
| `APP_NAME` | `Leadhub` | 应用名，会出现在 OpenAPI 标题 |
| `APP_ENV` | `dev` | `dev` / `test` / `prod` |
| `DEBUG` | `false` | 是否启用调试模式（生成 .env 时为 false；dev 调试时改 true） |
| `API_V1_PREFIX` | `/api/v1` | API 路由前缀 |

### 安全

| 变量 | 默认值 | 说明 |
|---|---|---|
| `SECRET_KEY` | 必填 | JWT 签名密钥，生产环境用 `openssl rand -hex 32` 生成 |
| `JWT_ALGORITHM` | `HS256` | JWT 算法 |
| `JWT_EXPIRE_MINUTES` | `60` | Token 过期时间（分钟） |

### 服务监听

| 变量 | 默认值 | 说明 |
|---|---|---|
| `HOST` | `0.0.0.0` | 监听地址 |
| `PORT` | `8000` | 监听端口 |
| `WORKERS` | `1` | Uvicorn worker 数（生产环境按 CPU 调整） |

### 数据库

| 变量 | 默认值 | 说明 |
|---|---|---|
| `POSTGRES_HOST` | `localhost` | uvicorn 在宿主机上跑；容器内改为 `postgres` |
| `POSTGRES_PORT` | `5432` | 5432 |
| `POSTGRES_USER` | `youzi-leadhub` | |
| `POSTGRES_PASSWORD` | 随机生成 | init.py 自动写入 |
| `POSTGRES_DB` | `youzi-leadhub` | |

> 默认 `POSTGRES_HOST=localhost`（uvicorn 在宿主机上跑）。
> 如在 docker 容器内运行（`docker compose exec backend ...`），改成 `postgres`。

### Redis

| 变量 | 默认值 |
|---|---|
| `REDIS_HOST` | `localhost` |
| `REDIS_PORT` | `6379` |
| `REDIS_PASSWORD` | （无密码） |

### CORS

`.env` 中：

```env
CORS_ORIGINS=["http://localhost:3000","http://localhost:3000"]
```

JSON 数组，按需添加域名。**生产环境只保留可信域名**（删掉 `localhost`）。

### 日志

| 变量 | 默认值 | 说明 |
|---|---|---|
| `LOG_LEVEL` | `INFO` | DEBUG/INFO/WARNING/ERROR |
| `LOG_FORMAT` | `text` | `text` / `json`（**生产推荐 json** 便于日志聚合） |

### 初始化

| 变量 | 默认值 | 说明 |
|---|---|---|
| `INITIAL_ADMIN_USERNAME` | `admin` | 首次启动时创建的管理员用户名 |
| `INITIAL_ADMIN_PASSWORD` | **随机生成** | 默认密码由 init.py 随机生成（启动后端时控制台打印） |
| `INITIAL_ADMIN_EMAIL` | `admin@example.com` | 邮箱 |

### 数据库自动维护

| 变量 | 默认值 | 说明 |
|---|---|---|
| `AUTO_INIT_DB` | `true` | 首次启动 `create_all` 建表（**不**自动 stamp）；后续启动执行 `alembic upgrade head` |
| `AUTO_SEED_DATA` | `true` | 自动插入种子数据（默认管理员 + demo 用户 + 角色，dev 环境） |

> 首次启动**故意不 stamp alembic**，避免后续 `make db-migrate MSG="add xxx"` 生成空迁移。
> 迁移基线由首次启动自动建立（stamp 0001_baseline），加模块直接 `make db-migrate MSG="add xxx"`。
> 关闭 `AUTO_INIT_DB` 后：需手动跑 `alembic upgrade head`。

## 生产环境建议（一次性配置）

1. 修改 `SECRET_KEY`：`openssl rand -hex 32`
2. `DEBUG=false`
3. `LOG_FORMAT=json`
4. `CORS_ORIGINS` 只保留生产域名（删删除 `localhost`）
5. 用 `make reset-admin` 设置强 admin 密码
