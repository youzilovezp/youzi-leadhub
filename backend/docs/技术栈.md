# Leadhub 后端技术栈

> 非技术用户**不需要**读这个文档。仅供团队成员了解。

## 核心框架

| 组件 | 用途 |
|---|---|
| Python 3.11+ | 主语言 |
| FastAPI | Web 框架（异步、自动 OpenAPI） |
| Uvicorn | ASGI 服务器 |
| Pydantic v2 | 数据校验 |
| Pydantic Settings | 配置加载 |

## 数据库

| 组件 | 用途 |
|---|---|
| SQLAlchemy 2.0 | ORM（异步） |
| Alembic | 数据库迁移 |
| asyncpg | PostgreSQL 异步驱动 |
| psycopg2-binary | PostgreSQL 同步驱动（alembic 用） |

## 安全

| 组件 | 用途 |
|---|---|
| PyJWT | JWT 编解码（含 jti，用于 logout 黑名单） |
| bcrypt | 密码哈希 |

## 中间件（按启用情况）

- **adminer**：数据库 UI（按需启动）

## 工具

| 组件 | 用途 |
|---|---|
| loguru | 日志（统一格式 + stdout） |
| httpx | 异步 HTTP 客户端（测试、调用外部 API） |

## 开发工具

| 组件 | 用途 |
|---|---|
| uv（推荐）| 依赖管理 |
| ruff | 代码风格 + Linter |
| mypy | 静态类型检查 |
| pytest + pytest-asyncio | 测试 |
| Docker | 容器化 |
