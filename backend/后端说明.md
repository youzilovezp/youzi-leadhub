# Leadhub 后端

基于 FastAPI + SQLAlchemy 2.0（异步）的管理系统后端。

## 启动

```bash
# 推荐：用工程根目录的 Makefile（自动准备中间件 + venv）
cd .. && make install && make backend-dev

# 或手动：
pip install -e ".[dev]"
cd .. && make start        # 先确保 PostgreSQL 就绪（复用本机 / Docker 起）
cd backend && uvicorn app.main:app --reload
```

或者用工程根目录的 Makefile：

```bash
cd .. && make backend-dev
```

启动后访问：

- API 文档：http://localhost:8000/docs
- 数据库 UI：http://localhost:8080（adminer）

## 项目结构

```
backend/
├── app/                # 应用代码
│   ├── api/            # 路由层
│   ├── core/           # 配置、安全、异常、日志
│   ├── crud/           # 数据访问
│   ├── db/             # 数据库连接（含 init_db.py 自动建表）
│   ├── middleware/     # 中间件
│   ├── models/         # ORM 模型
│   ├── schemas/        # Pydantic 模型
│   ├── services/       # 业务逻辑
│   ├── api/
│   │   └── deps.py     # 依赖注入（SessionDep / CurrentUser / SuperUser）
│   └── main.py         # 入口
├── alembic/            # 数据库迁移
├── docs/               # 架构/技术栈/配置/开发/API 文档
├── tests/              # 测试
├── scripts/            # 辅助脚本
│   ├── reset_admin.py   # 重置管理员密码
│   └── start.sh        # 启动脚本（从 .env 读 PORT）
├── docker/             # Dockerfile
├── .env.example        # 环境变量样例
└── pyproject.toml
```

## 加新业务模块

```bash
python3 scripts/add_module.py order --title "订单管理"
```

脚本自动生成后端 4 个文件（model/schema/crud/router；admin 模式检测到前端工程时再生成 view/api），并打印你需要手动注册的地方。

## 日常用到的命令

```bash
make help               # 查看完整命令列表
make install            # 装依赖（创建 venv）
make backend-dev        # 启动后端（自动准备中间件 + 建表 + 种子）
make test               # 跑测试
make db-migrate MSG="add xxx"  # 生成迁移
make db-upgrade         # 应用迁移
make db-downgrade       # ⚠️ 回滚一步
make reset-admin        # 重置管理员密码（默认重置为 admin）
make admin-pass NEW=xxx # 重置为指定密码
make start              # 启动中间件（优先复用本机已有服务，缺的用 Docker 起）
make stop               # 停止 Docker 中间件容器
make backup             # 备份数据库到 backups/（PG 用 pg_dump）
```
