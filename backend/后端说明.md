# Leadhub 后端

FastAPI + SQLAlchemy 2（异步）+ PostgreSQL 的线索采集后端。

## 启动

```bash
cd .. && make backend-dev    # 推荐：自动准备中间件 + venv + 建表 + 种子
```

- API 文档 http://localhost:8000/docs ／ 健康检查 `/healthz`、`/readyz`
- 启动日志会打印默认管理员密码（dev 环境另有 manager/alice/bob 演示账号，密码 `Demo@123`）
- 常用命令（备份/迁移/切库）见根目录 [README](../README.md)
