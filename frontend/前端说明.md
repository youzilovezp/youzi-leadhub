# Leadhub 前端

Vue 3 + TypeScript + Vite + Naive UI + TailwindCSS v4 的管理控制台（暗色模式 / 主题色切换 / ECharts 图表）。

## 启动

```bash
cd .. && make frontend-dev    # 推荐（默认 http://localhost:3000）

# 或直接：
pnpm install && pnpm dev
```

- 登录账号与后端一致：见 `backend/.env` 的 `INITIAL_ADMIN_PASSWORD`（本地默认 `admin/admin`）
- 换主题（暗色 / 主题色）：顶栏右侧工具组，无需改代码，详见 [开发指南 §主题定制](docs/开发指南.md)
