# Leadhub 前端

基于 Vue 3 + TypeScript + Vite + Naive UI + TailwindCSS v4 + @vueuse/core 的管理系统前端（暗色模式 / 主题色切换 / ECharts 图表）。

## 启动

```bash
pnpm install      # 或 npm install

# 启动开发服务器（默认 http://localhost:3000）
pnpm dev

# 构建生产版本
pnpm build
```

或用工程根目录的 Makefile：

```bash
cd .. && make frontend-dev
```

启动后访问：

- 前端：http://localhost:3000

## 默认账号

`admin` / `admin`（admin 模式密码在 backend/.env；本前端对接的后端工程配置）。（生产前必须改）

## 主题定制

顶栏右侧的主题工具组支持 **暗色切换** 与 **主题色一键切换**，全部基于 CSS 变量 + localStorage 持久化，无需改代码即可换肤。

### 暗色模式

- 切换入口：顶栏月亮/太阳图标（`appStore.toggleDark()`）
- 实现：`html.dark` class + Naive UI 官方暗色变量；跟随系统（`auto`）/ 亮 / 暗三态
- 持久化键：`youzi-app-theme`（值为 `auto` / `light` / `dark`）

### 主题色色板

顶栏调色板图标内置 6 个预设（`src/stores/app.ts` 的 `THEME_PRESETS`）：

| 名称   | 色值     |
| ------ | -------- |
| 柚子橙 | `#f59e0b` |
| 品牌蓝 | `#409eff` |
| 紫罗兰 | `#7c3aed` |
| 翡翠绿 | `#10b981` |
| 赤霞红 | `#ef4444` |
| 黛青蓝 | `#0ea5e9` |

选中后 `setPrimaryColor()` 会自动计算 primary 的 `light-3/5/7/8/9` 与 `dark-2` 梯度写入 `--el-color-primary*` CSS 变量——Naive UI 组件、Tailwind 工具类（`bg-primary`、`text-primary` 等）与登录页渐变背景全部跟随。持久化键：`youzi-app-primary`。

### 扩展色板

想加自己的品牌色，在 `src/stores/app.ts` 的 `THEME_PRESETS` 数组追加一项即可，顶栏色板自动渲染：

```ts
export const THEME_PRESETS: ThemePreset[] = [
  // ...原有预设
  { name: '我的品牌色', color: '#ff6900' },
]
```

### 相关 localStorage 键一览

| 键                        | 作用             | 默认值    |
| ------------------------- | ---------------- | --------- |
| `youzi-app-theme`         | 暗色三态         | `auto`    |
| `youzi-app-primary`       | 主题色 hex       | `#f59e0b` |
| `youzi-app-sidebar-collapsed` | 侧边栏折叠   | `false`   |

## 加新业务模块

在工程根目录：

```bash
python3 backend/scripts/add_module.py order --title "订单管理"
```

脚本会自动生成前端需要的 2 个文件：

- `src/api/order.ts` —— axios 接口
- `src/views/order/index.vue` —— CRUD 页面

并提示你需要做的 **5 步手动注册**（前后端合计）：

1. `backend/app/models/__init__.py` 加 `from app.models.order import Order`
2. `backend/app/api/v1/router.py` 加 `from ... import router as order_router` + `include_router(...)`
3. `frontend/src/router/index.ts` 加路由记录
4. `frontend/src/layouts/BasicLayout.vue` 加菜单项
5. `make db-migrate MSG="add order"` 然后 `make db-upgrade`（在后端工程目录跑）
