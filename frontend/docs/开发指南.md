# Leadhub 前端开发指南

> 面向工程师：本地开发、加页面、换主题。非技术用户看 [使用手册](../../docs/使用手册.md) 即可。

## 1. 环境准备

- Node.js >= 18
- pnpm（推荐）或 npm

## 2. 安装与启动

```bash
pnpm install
pnpm dev        # 默认 http://localhost:3000；或用根目录 make frontend-dev
```

后端地址等环境变量见 [配置说明](配置说明.md)。

## 3. 添加新页面

推荐先跑根目录脚本生成骨架（自动产出 `src/api/<模块>.ts` + `src/views/<模块>/index.vue`）：

```bash
python3 backend/scripts/add_module.py order --title "订单管理"
```

生成后还需手动注册路由/菜单等 **5 步**——完整清单以根目录 [AGENTS.md](../../AGENTS.md) 为权威。

脚本生成的不够用时手写：

**API 模块**（`src/api/article.ts`）：

```ts
import request from "./request";

export interface Article {
  id: number;
  title: string;
  content: string;
  created_at: string;
}

export function listArticles() {
  return request.get<Article[], Article[]>("/articles");
}

export function createArticle(payload: Partial<Article>) {
  return request.post<Article, Article>("/articles", payload);
}
```

**页面**：参考 `src/views/system/user/index.vue`（表格 + 新增/编辑弹窗的完整范例）。

## 4. 主题定制

顶栏右侧的主题工具组支持**暗色切换**与**主题色一键切换**，全部基于 CSS 变量 + localStorage 持久化，无需改代码即可换肤。

### 暗色模式

- 切换入口：顶栏月亮/太阳图标（`appStore.toggleDark()`）
- 实现：`html.dark` class + Naive UI 官方暗色变量；跟随系统（`auto`）/ 亮 / 暗三态
- 持久化键：`youzi-app-theme`（值为 `auto` / `light` / `dark`）

### 主题色色板

顶栏调色板图标内置 6 个预设（`src/stores/app.ts` 的 `THEME_PRESETS`）：

| 名称   | 色值     |
| ------ | -------- |
| 柚子橙 | `#f59e0b` |
| 品牌蓝 | `#409eff` |
| 紫罗兰 | `#7c3aed` |
| 翡翠绿 | `#10b981` |
| 赤霞红 | `#ef4444` |
| 黛青蓝 | `#0ea5e9` |

选中后 `setPrimaryColor()` 自动计算 primary 的 `light-3/5/7/8/9` 与 `dark-2` 梯度写入 `--el-color-primary*` CSS 变量——Naive UI 组件、Tailwind 工具类（`bg-primary`、`text-primary` 等）与登录页渐变背景全部跟随。持久化键：`youzi-app-primary`。

### 扩展色板

想加自己的品牌色，在 `src/stores/app.ts` 的 `THEME_PRESETS` 数组追加一项即可，顶栏色板自动渲染：

```ts
export const THEME_PRESETS: ThemePreset[] = [
  // ...原有预设
  { name: '我的品牌色', color: '#ff6900' },
]
```

### 相关 localStorage 键一览

| 键                        | 作用             | 默认值    |
| ------------------------- | ---------------- | --------- |
| `youzi-app-theme`         | 暗色三态         | `auto`    |
| `youzi-app-primary`       | 主题色 hex       | `#f59e0b` |
| `youzi-app-sidebar-collapsed` | 侧边栏折叠   | `false`   |

## 5. 测试 & 检查

```bash
pnpm type-check   # 类型检查（必须通过）
pnpm build        # 生产构建
```

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 跨域错误 | 开发环境检查 `vite.config.ts` 的 proxy；生产走 Nginx 反代 |
| 修改 .env 后没生效 | 必须重启 Vite 开发服务器 |
| 自动导入不生效 | 确认 `auto-imports.d.ts`、`components.d.ts` 在 `tsconfig.json` 的 include 中 |
