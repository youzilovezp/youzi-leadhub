# Leadhub 前端开发指南

> 非技术用户**不需要**读这个文档。仅供工程师添加新功能时参考。

## 1. 环境准备

- Node.js >= 18
- pnpm（推荐）或 npm

## 2. 安装依赖

```bash
pnpm install
# 或 npm install
```

## 3. 启动开发服务器

```bash
pnpm dev
```

默认监听 `http://localhost:3000`。

## 4. 配置后端地址

编辑 `.env.development`：

```env
VITE_PROXY_TARGET=http://localhost:8000
```

重启 Vite 生效。

## 5. 添加新业务模块（推荐用脚本）

在工程根目录：

```bash
python3 backend/scripts/add_module.py order --title "订单管理"
```

脚本会自动生成：

- `src/api/order.ts` —— axios 接口
- `src/views/order/index.vue` —— CRUD 页面（表格 + 新增/编辑弹窗）

然后你需要：

1. 在 `src/router/index.ts` 的 children 中加路由
2. 在 `src/layouts/BasicLayout.vue` 的 menus 中加菜单项

加上后端还要做的 3 步，总共 **5 步手动注册**（详见根目录的 `项目说明.md`）。

## 6. 手动添加新页面（不推荐，了解即可）

如果脚本生成的不够用，可手动加。

### 6.1 创建 API 模块（`src/api/article.ts`）

```ts
import request from "./request";

export interface Article {
  id: number;
  title: string;
  content: string;
  created_at: string;
}

export function listArticles() {
  return request.get<Article[], Article[]>("/articles");
}

export function createArticle(payload: Partial<Article>) {
  return request.post<Article, Article>("/articles", payload);
}
```

### 6.2 创建页面（`src/views/article/index.vue`）

参考 `src/views/system/user/index.vue` 实现。

### 6.3 注册路由（`src/router/index.ts`）

```ts
{
  path: 'article',
  name: 'Article',
  component: () => import('@/views/article/index.vue'),
  meta: { title: '文章管理', icon: 'Document' },
}
```

### 6.4 添加菜单（`src/layouts/BasicLayout.vue`）

```ts
const menus = [
  // ...
  { path: "/article", title: "文章管理", icon: "Document" },
];
```

## 7. 测试 & 检查

```bash
pnpm type-check   # 类型检查（必须通过）
pnpm build        # 生产构建
```

## 8. 常见问题

### Q: 跨域错误

A: 开发环境检查 `vite.config.ts` 中的 proxy 配置；生产环境通过 Nginx 反代。

### Q: 修改 .env 后没生效

A: 必须重启 Vite 开发服务器。

### Q: 自动导入不生效

A: 确认 `auto-imports.d.ts` 和 `components.d.ts` 在 `tsconfig.json` 的 include 中。
