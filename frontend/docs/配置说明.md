# Leadhub 前端配置说明

> 普通用户**不需要**改任何字段。所有配置项都有合理默认值。

## 1. 环境变量文件

| 文件               | 用途                 | 是否提交     |
| ------------------ | -------------------- | ------------ |
| `.env.development` | 开发环境             | ✅           |
| `.env.production`  | 生产环境             | ✅           |
| `.env.local`       | 本地覆盖（个人配置） | ❌ gitignore |

## 2. 变量说明

| 变量                | 类型 | 默认值                  | 说明                             |
| ------------------- | ---- | ----------------------- | -------------------------------- |
| `VITE_APP_TITLE`    | str  | -                       | 网站标题（init.py 替换为项目名） |
| `VITE_API_BASE_URL` | str  | `/api/v1`               | API 基础路径                     |
| `VITE_PROXY_TARGET` | str  | `http://localhost:8000` | 开发环境代理目标                 |
| `VITE_TOKEN_KEY`    | str  | `access_token`          | localStorage 中 token 的 key     |

> **变量必须以 `VITE_` 前缀**，Vite 才会暴露给客户端代码。
> **不要在变量里放密钥/token**。

## 3. 修改后端地址

如果改了后端端口（默认 8000），编辑 `.env.development`：

```env
VITE_PROXY_TARGET=http://localhost:8050
```

重启 `pnpm dev` 生效。

## 4. 业务代码访问

```ts
// 直接（不推荐）
import.meta.env.VITE_APP_TITLE;

// 统一（推荐）
import { APP_TITLE, API_BASE_URL } from "@/config";
```

## 5. 生产部署

```bash
pnpm build    # 产物在 dist/
```

Nginx 托管、HTTPS、API 反代与安全 header 的完整配置见 [运维部署 §2.4](../../docs/运维部署.md)。
