# Leadhub 前端技术栈

> 非技术用户**不需要**读这个文档。仅供工程师了解。

## 核心

| 组件       | 版本 | 用途                              |
| ---------- | ---- | --------------------------------- |
| Vue        | ^3.4 | 渐进式 UI 框架（Composition API） |
| TypeScript | ~5.4 | 类型系统                          |
| Vite       | ^5.1 | 构建工具                          |
| Pinia      | ^2.1 | 状态管理                          |
| Vue Router | ^4.3 | 路由                              |

## UI

| 组件                    | 版本 | 用途                              |
| ----------------------- | ---- | --------------------------------- |
| Naive UI            | ^2.6 | 中后台组件库                      |
| @naive-ui/icons-vue | ^2.3 | Naive UI 图标                 |
| TailwindCSS             | 4.3  | 原子化 CSS（v4，设计令牌接入 EP 变量） |
| SCSS                    | -    | CSS 预处理器                      |
