# 📦 /yz:leadhub · 安装说明

> 只讲安装 / 更新 / 卸载，全程约 10 分钟（含服务首次启动）。怎么用看 [📖 使用手册.md](使用手册.md)，项目总览看 [👋 README.md](README.md)。

## 1. 先装好这几样

| 工具 | 最低版本 | 检查命令 | 没装的怎么办 |
|---|---|---|---|
| 🐍 Python | 3.11+ | `python3 --version` | [python.org](https://python.org) |
| 🟢 Node.js | 18+ | `node --version` | [nodejs.org](https://nodejs.org) |
| 🐳 Docker | 任意 | `docker --version` | 可选——本机已有 PostgreSQL 可跳过 |
| 🤖 宿主工具 | 任意一个 | Claude Code / opencode / codex / easycode | 任选 |

> ⚠️ 目前支持 macOS / Linux。Windows 用户请先用 [WSL](https://learn.microsoft.com/windows/wsl/install)。

## 2. 安装 · Skill 本体

skill 目录在本工程的 `skill/` 下，一条命令装到全部 4 个宿主：

```bash
cd <本工程目录>/skill
./install.sh                # 全部：Claude Code + opencode + codex + easycode

# 或只装指定宿主
./install.sh claude opencode
```

各宿主的安装位置与命令名（软链接，改工程源码即时生效）：

| 宿主 | 位置 | 命令 |
|---|---|---|
| Claude Code | `~/.claude/skills/yz:leadhub` | `/yz:leadhub`（主命令，支持冒号） |
| opencode | `~/.config/opencode/skills/yz-leadhub` | `/yz-leadhub` |
| codex | `~/.codex/skills/yz-leadhub` | `/yz-leadhub` |
| easycode | `~/.agents/skills/yz-leadhub`（Vercel Agents 跨端标准） | `/yz-leadhub` |

> 💡 两个入口功能完全相同：Claude Code 支持冒号命名用 `/yz:leadhub`；opencode 等宿主不支持 `:`，自动落到兼容入口 `/yz-leadhub`（指向 `skill/compat/`，与主 skill 共享同一 CLI 与文档）。

验证：

```bash
test -f ~/.claude/skills/yz:leadhub/SKILL.md && echo "✓ SKILL.md OK"
```

> ⚠️ **完全退出宿主工具再重开**（Mac: Cmd+Q），否则识别不到新 skill。

## 3. 服务依赖（首次启动自动完成）

`/yz:leadhub start`（或 `make dev`）首次启动会自动：

1. 建 Python venv + 装后端依赖、装前端 node_modules（约 3-5 分钟）
2. 起 PostgreSQL（优先复用本机已运行的；缺的用 Docker 起）
3. 建库建表 + 种子管理员（admin/admin）

**可选配置**（`backend/.env`）：

```bash
GOOGLE_MAPS_API_KEY=xxx    # 用 google_maps 采集器必填（Google Cloud 开通 Places API）
SCHEDULER_ENABLED=true     # cron 定时调度（多 worker 只在一个进程开）
```

## 4. 验证安装

```bash
python3 <本工程目录>/skill/scripts/leadhub.py status
```

期望输出：`🟢 服务运行中: http://127.0.0.1:8000/api/v1 …`

也可以打开宿主工具输入 `/yz:leadhub`，出现自动补全 = 成功。

## 5. 更新

```bash
cd <本工程目录> && git pull     # 更新工程源码（软链接即时生效）
```

服务代码变更由后端 `--reload` 自动热载；结构变更重启：`leadhub.py stop && leadhub.py start`。

## 6. 卸载

```bash
cd <本工程目录>/skill && ./install.sh --uninstall   # 移除 4 个宿主的软链接
python3 skill/scripts/leadhub.py stop               # 停服务（可选）
make stop                                            # 停 Docker PG（可选）
```

## 7. 常见问题

| 问题 | 解决 |
|---|---|
| 装完不识别 `/yz:leadhub` | 完全退出宿主工具再重开；还不行重跑 `./install.sh` |
| `start` 90s 未就绪 | `tail -50 /tmp/yz:leadhub-dev.log` 看真实报错 |
| 端口被占（8000/3000/5432） | 改 `backend/.env` 的 `PORT`/`FRONTEND_PORT`/`POSTGRES_PORT`，CLI 跟着 `LEADHUB_URL` 环境变量走 |
| 本机 PG 认证失败 | 首选改 `.env` 的 `POSTGRES_PORT` 走 Docker 独立实例 |
| google_maps 任务 failed | `backend/.env` 未配 `GOOGLE_MAPS_API_KEY` |
| 想复制安装而非软链接 | 可以，但请 `export LEADHUB_DIR=<工程路径>`，否则 start/stop 找不到工程根 |
