# § 1 三分钟路径（老用户）

> 📌 **装好 skill？直接看下面三步。**

## 1.1 跑

打开 Claude Code / opencode / codex / easycode，输入：

```
/yz:leadhub 采集一批在招 WhatsApp 客服的公司
```

AI 会自动：`status`（没起就 `start`）→ `task-create job_posting --wait` → 贴出进度和结果：

```
⏳ 任务执行中…
✅ 终态 completed ｜ 新增 10 / 合并 5
#12   95分 [WA 在招] Amare Group Inc.   PH +63917...
```

## 1.2 看结果

- 对话内：`/yz:leadhub 列出 40 分以上且检测到 WhatsApp 的线索`
- Web 管理台：浏览器开 `http://localhost:8000/docs`（API）/ 前端 `http://localhost:3101`（管理界面）
- 给销售：`/yz:leadhub 导出高意向线索`

## 1.3 没看到 `/yz:leadhub` 命令？

- opencode / codex / easycode 等不支持冒号命名的宿主用兼容入口：**`/yz-leadhub`**（功能完全相同）
- 还是看不到：完全退出宿主工具（Cmd+Q）再重开

# § 2 从零开始（新手）

> 🆕 **第一次用？4 步走。**

## 2.1 装好前置 + skill

按 [📦 安装说明.md](安装说明.md) § 1-2 装好 Python 3.11+ / Node 18+ / 宿主工具，然后：

```bash
cd <本工程目录>/skill && ./install.sh
```

## 2.2 首次启动服务

```
/yz:leadhub 启动服务
```

首次约 5-8 分钟（装依赖 + 起数据库 + 建表）。完成后默认账号 `admin/admin`。

## 2.3 采集第一批线索

```
/yz:leadhub 跑一个招聘监控任务，关键词 whatsapp，翻 2 页，等结果
```

（想用 Google Maps 采集需先在 `backend/.env` 配 `GOOGLE_MAPS_API_KEY`）

```
/yz:leadhub 全库检测 WhatsApp，完成后导出 40 分以上的
```

AI 执行：`check-whatsapp --wait` → `leads --min-score 40 --whatsapp hit` → `export -o hot-leads.csv`

# § 3 速查表

> 🔍 **忘了命令？AI 会自己翻译自然语言，这里是你想精确控制时的原生命令。**

```bash
L="python3 ~/.claude/skills/yz:leadhub/scripts/leadhub.py"

$L status                                  # 服务状态 + 线索总览
$L start / stop                            # 启停服务
$L task-create job_posting -p keywords=whatsapp --wait
$L task-create google_maps -p country=MY -p cities="Kuala Lumpur" -p keywords="dental clinic" --wait
$L task-create website_enrich              # 全库富化（有网站且24h未成功富化）
$L task-list [--status running]            # 任务列表
$L task-logs 3 -f                          # 跟日志到终态
$L task-run 3 / task-cancel 3              # 重跑 / 取消
$L check-whatsapp 5 6 7 --wait             # 指定线索检测 WhatsApp
$L leads --country PH --min-score 40 --whatsapp hit --limit 50
$L export -o hot-leads.csv                 # 全字段 CSV（utf-8-sig，Excel 直开）
```

# § 4 完整命令 + 场景

## 4.1 跑一次要多久？

| 操作 | 时间 |
|---|---|
| job_posting 1 页（15 岗位） | ~20s |
| website_enrich 100 站点 | 3-8 分钟（并发 5，每站 ≤3 请求） |
| google_maps 1 城市 1 关键词（≤60 条） | ~30s |
| 服务冷启动（非首次） | ~10s |

## 4.2 三个采集器怎么选？

| 你想要 | 用 | 原理 |
|---|---|---|
| 某城市某行业的企业名单+电话 | `google_maps` | Maps 官方 API，数据最干净 |
| 正在招 WhatsApp 客服的公司（=正在选型） | `job_posting` | kalibrr 招聘页 → 公司级线索 |
| 已有名单验证「官网有没有 WhatsApp」 | `website_enrich` | 指纹检测 wa.me/ht-ctc/joinchat… |

三个源进同一线索库，同企业自动去重合并、评分累加信号。

## 4.3 评分怎么读？

满分 110：插件 40 + 在招 30 + 官网 10 + 邮箱 10 + 目标地区 10 + 电话 5 + 社媒 5。
`≥40` = 高意向（至少命中插件或在招其一）；`≥70` = 两者都中，优先跟。

## 4.4 会重复采集吗？

不会。同企业多来源按「域名 > E.164 电话 > 归一化名+城市」合并成一条，来源记录按 (线索, 来源) 唯一；富化 24h 内成功的自动跳过。

# § 5 进阶配置

## 5.1 定时任务（cron）

```bash
$L task-create job_posting -p keywords=whatsapp --cron '0 9 * * *'   # 每天 9 点
```

cron 存数据库，服务重启自动恢复。**注意**：多 worker 部署时只有一个进程开 `SCHEDULER_ENABLED=true`。

## 5.2 调评分权重

`backend/.env`：

```bash
SCORING_WEIGHTS={"whatsapp_plugin": 50}   # 覆盖默认 40，其余不变
TARGET_REGIONS=MY,SG,ID,TH,PH,VN          # 收缩/扩大目标地区
```

改完重启服务生效。

## 5.3 采集并发与超时

```bash
COLLECT_MAX_CONCURRENT=2    # 同时运行任务数（满则排队不失败）
COLLECT_TASK_TIMEOUT=3600   # 单任务超时秒
ENRICH_CONCURRENCY=5        # 富化并发站点数
```

## 5.4 新增采集器

工程 `backend/app/collectors/` 继承 `Collector` 实现 `run()`，`_REGISTRY` 注册一行即接入全部体系。详见 `docs/业务逻辑.md` § 11。

# § 6 FAQ + 故障排查

## 6.1 FAQ

### Q1: 导出的 CSV Excel 打开乱码？

不会。导出用 `utf-8-sig` BOM 编码，Excel 双击直开。

### Q2: 检测 WhatsApp 会漏吗？

指纹库覆盖 wa.me / api.whatsapp.com / wp.whatsapp.com 及主流插件（ht-ctc、joinchat、getbutton、chaty、elfsight 等）；页面纯图片联系方式（电话写死在图里）检不出——这是 HTTP 富化的边界，量级 <5%。

### Q3: 数据会重复计分吗？

不会。在招信号按公司只计一次（多岗位合并一条线索）；插件+在招双命中是合理的高分。

### Q4: 可以多人同时用吗？

可以。服务是标准 Web 应用，多人开 Web 管理台或各自装 skill 指向同一 `LEADHUB_URL`。

### Q5: 爬 kalibrr 合规吗？

读取公开列表页、低频（默认每任务 ≤10 页）、带 UA；商用前请自行评估目标站点 ToS。Places API 走官方付费通道，注意商家字段存储期限条款。

## 6.2 故障排查

### 1. `无法连接 … 服务未启动`

```bash
$L start           # 没起就起
tail -50 /tmp/yz:leadhub-dev.log   # 起不来看真实报错
```

### 2. `start` 90s 未就绪

首次启动在装依赖（3-5 分钟属正常），`tail -f /tmp/yz:leadhub-dev.log` 等待；报数据库认证失败按日志中文指引改 `POSTGRES_PORT` 走 Docker。

### 3. google_maps 任务 failed「未配置 GOOGLE_MAPS_API_KEY」

`backend/.env` 加 `GOOGLE_MAPS_API_KEY=xxx`，重跑任务 `task-run <id>`。

### 4. 部分线索「首页抓取失败」

目标站挂了/拒绝访问，24h 内不会重试成功过的，失败的下次全量富化自动重跑；持续失败可人工核对该站是否存活。

### 5. 端口冲突

`backend/.env` 改 `PORT`/`FRONTEND_PORT`/`POSTGRES_PORT`；CLI 用 `export LEADHUB_URL=http://127.0.0.1:<新端口>` 跟随。

### 6. skill 改了没生效

软链接安装改源码即时生效；宿主工具的 skill 列表需重开会话刷新。
