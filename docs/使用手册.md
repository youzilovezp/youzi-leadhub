# 使用手册

> 面向每天使用本系统的人：**销售**怎么找线索、跟进、成交；**管理员**怎么建采集任务、管账号。
> 系统怎么跑起来看 [README](../README.md)；业务为什么这样设计看 [业务逻辑](业务逻辑.md)；生产部署与故障排查看 [运维部署](运维部署.md)。

## 登录与账号

- 地址 http://localhost:3000（部署后为你的域名），账号 `admin`，密码见 `backend/.env` 的 `INITIAL_ADMIN_PASSWORD`（本地默认 `admin`）。
- 连续输错 5 次会锁定（60 秒起步、逐次翻倍），等一会儿或找管理员处理。
- 内置 5 个角色：`admin` 超管 / `sales_manager` 销售主管 / `sales` 销售 / `operator` 运营 / `data_admin` 数据分析。
- **数据权限三级**：`all` 看全部 / `team` 本团队 + 共享池 / `own` 仅自己 + 共享池。看不到某些线索是权限使然，不是丢了。

## 销售：每天的打开方式

### ① 今日商机

**今日商机**页每天自动汇总三类最值得联系的客户：

| 板块 | 含义 |
|---|---|
| 新晋 S/A | 今天刚升到 S / A 级的企业 |
| 新增高分 | 今天新入库、≥60 分且确认是中国出海企业 |
| 高价值预警 | 今天出现重要动态（发现 WhatsApp、SaaS 信号、升级等） |

列表标签：`FB私域` = Facebook 主页挂了 WhatsApp 入口（高意向）；`WA` = 官网检测到 WhatsApp。

### ② 领取

跟进人显示**共享池**的行可点「**领取**」——线索归你，别人不再能领（防撞单）。他人已持有的行显示「已认领」。

### ③ 跟进

线索列表行操作「**跟进**」：选状态、写备注、可设下次回访时间。状态主线：

```
待跟进 → 已联系 → 已回复 → 有效商机 → 报价 → 谈判 → 成交
                （另有无效 / 暂不考虑 两个终态）
```

每次跟进都会写进该线索的时间线，换人接手能看全历史。

### ④ 该回访了

列表筛选「该回访」= 到了约定回访时间还没跟的客户；顶部统计条的「该回访」数字同口径，每天先清这个。

## 线索列表

### 筛选

| 筛选项 | 说明 |
|---|---|
| 等级 | S（≥80 立即跟进）/ A（≥60 高潜力）/ B（≥40 培育）/ C |
| 中国出海 | 默认只看确认是中国出海的企业；选「全部（不过滤）」才含国外与待验证 |
| 国家 / 城市 / 行业 / 来源 | 常规维度；来源含 Meta 广告库、招聘监控、网站富化、手工录入等 |
| WhatsApp | 已检测到 / 未检测到 |
| 最低分 / 关键词 | 分数下限；企业名、域名等模糊搜索 |
| 跟进状态 / 跟进人 / 该回访 | 跟进工作流三件套 |

顶部统计条每 15 秒自动刷新（总量、等级分布、待跟进、该回访等）。

### 检测 WhatsApp

勾选若干行 →「**检测 WhatsApp**」→ 系统创建一个富化任务并跳到任务详情页看进度。完成后线索的 WhatsApp 入口、官网、邮箱、社媒等信息自动更新，分数同步重算。

### 手工录入

「手工录入」按钮：填表即入库，和采集来的数据走同一套去重合并——重复的企业不会建两条。

### 导出 CSV

「**导出 CSV**」：按**当前筛选口径**导出，弹窗里勾选要哪些列（36 列可选），Excel 直接打开不乱码。上限 5 万行。

## 线索详情（企业画像）

点企业名进入，一页回答三个问题：**为什么需要你、应该卖什么、该找谁。**

| 区块 | 看什么 |
|---|---|
| 六维评分条 | 出海 25% / WhatsApp 30% / SaaS 需求 20% / 规模 10% / 营销 10% / 联系人 5%，哪维强一目了然 |
| 基础信息 | 国家、行业、官网、来源等 |
| WhatsApp 画像 | 入口链接、场景标签（客服 / 营销 / 交易通知） |
| SaaS 需求 | CRM、工单、Chatbot 等需求信号 |
| 联系人 | 表格直接增删改；职位自动分层——决策层 / 市场客服 / 技术 |
| 推荐产品 + 销售建议 | 规则引擎按画像推荐（WA 消息 / 出海 SaaS / 广告代理三线）并给开口话术 |
| AI 分析 / 生成话术 | 按钮一键生成；未配 LLM 时自动降级为规则模板，照样能用 |
| 动态时间线 | 事件 + 跟进记录合并倒序，可加载更多 |

## 管理员

### 采集任务

1. 「创建任务」→ 选采集器 → 表单按采集器自动渲染（每个采集器参数不同，照提示填即可）。
2. 需要定时就把「cron 表达式」填上（如 `0 7 * * *` 每天早上 7 点）；不填则保存后立即跑一次。
3. 任务列表对活跃任务每 3 秒自动刷新；进详情页看进度条 + 实时滚动日志。

任务状态怎么读：

| 状态 | 含义 |
|---|---|
| queued | 排队中——并发闸门（默认同时 2 个）满了是**正常现象** |
| running | 执行中，进度实时更新 |
| completed / failed | 结束；failed 的日志里有原因，改完点「执行」重跑 |
| cancelled | 手动取消 |

注意：后端重启会把执行中的任务标为 failed（日志写「进程重启，任务中断」），重新点「执行」即可。`meta_ads` 采集器需要先在 `backend/.env` 配 `META_ADS_ACCESS_TOKEN`（免费申请，见 [业务逻辑 §4.0](业务逻辑.md)）。

### 数据源管理

每个渠道的任务数、成功率、数据量、最后运行时间，以及**渠道 × 等级**产出表——用来判断哪个渠道的商机产出最高，把资源投给赢家。

### 高价值预警

按时间倒序列出带预警标记的客户动态（发现 WhatsApp、出现 SaaS 信号、等级升 S/A…），是当日商机的补充视角。

### 质量抽检

系统的识别准不准，靠人抽检度量：选一个维度（WhatsApp 识别 / 出海判定 / 联系人有效）→ 逐条看系统给的证据 → 标「对 / 错 / 不确定」。顶部实时显示各维度准确率对目标线（WhatsApp ≥90%、出海 ≥80%、联系人 ≥60%）与 S+A 占比对 20% 目标。

### 用户与角色

- **用户管理**：增删改查、启用禁用、重置密码（管理员重置无需旧密码）。
- **角色管理**：按权限码勾选，共 7 个——`lead:read/write/delete`、`assign:lead`（分配线索）、`task:manage`（建任务）、`user:manage`、`stats:read`。超管拥有全部且不受限。

## 常见问题

| 问题 | 处理 |
|---|---|
| 登录被锁 | 等自动解锁；急用找管理员（[运维部署 §4.2](运维部署.md)） |
| 任务一直 queued | 前面有任务在跑属正常；长时间不动按 [运维部署 §4.1](运维部署.md) 排查 |
| 忘记密码 | 普通用户找管理员重置；admin 密码在服务器跑 `make admin-pass NEW='<新密码>'` |
| 导出慢 / 超时 | 先缩小筛选范围；大额导出需调服务端超时（[运维部署 §4.4](运维部署.md)） |
