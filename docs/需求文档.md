# 线索系统需求文档

> **V1 冻结版 · 2026-09-01 定稿** ｜ 需求唯一真源 ｜ 变更规则见 §11

## 0. 核心需求

> **作为一家 WhatsApp 中国的 BSP，我们想获取一些出海且在用 WhatsApp 承接客户的中国企业信息，用来出售 SaaS 服务（包括但不限于账号、承接客户、精细化运营等）和 WhatsApp 消息。我们开发这个线索系统，全部围绕这个核心需求服务。**

| 要素 | 内容 |
|---|---|
| 我们是谁 | WhatsApp 中国 BSP（Meta 官方授权服务商）；兼 Meta/TikTok 一级广告代理（延伸） |
| 要找谁 | 中国企业 ∧ 出海 ∧ **在用 WhatsApp 承接客户** |
| 卖什么 | ① SaaS 服务：账号（Business API 开通）、承接客户（客服/私域承接）、精细化运营　② WhatsApp 消息（营销/通知/客服消息量）　③ 延伸：广告代理同客双报价 |
| 系统职责 | 自动发现 → 评估排序 → 每天给销售一批可直接建联的客户 |

## 1. 系统定位

**自动发现、评估并排序「出海 × 用 WhatsApp 承接客户」的中国企业，让销售每天直接收到一批值得联系的客户。**

- 不是企业名录：系统获取的不是「企业」而是「商机信号」，每 1 分意向分可溯源到一条可核查证据。
- 核心价值是对每条线索回答三问：**为什么需要你（why）/ 应该卖什么（what）/ 应该找谁（who）**，三问齐备才进今日商机。
- 线索价值 = **销售拿到就能行动**。
- 批次为空时给根因诊断，不给空白。

## 2. 目标客户

客户分两层：**资格层**（是不是中国出海买家——ICP 门硬性准入）与**价值层**（是否已在用 WA 承接客户——意向分排序）。

### 2.1 资格层 · 正清单（中国出海企业 =）

| 算目标客户 | 说明 |
|---|---|
| 品牌方 / 跨境电商卖家 / 独立站 DTC | 主力客群 |
| 工厂 / 制造商 | 出海制造业 |
| 出海游戏 / App 公司 | |
| 出海工具 · 建站 SaaS 服务商（Shopline 类） | 是买家，不误杀 |

### 2.2 资格层 · 负清单（不是客户）

| 排除 | 判定依据 |
|---|---|
| 政府与事业单位 | gov.cn / edu.cn 域 + 名称词（人民政府 / 管委会 / 公共服务平台 / 海关 / 商务局 / 单一窗口 等） |
| 媒体 / 社区 / 论坛 / 门户 / 报告页 / 软件下载页 / 词典工具站 | 域名黑名单 + 名称词表（资讯 / 社区 / 论坛 / 白皮书 / 报告 / 下载 / 百科 / 导航 / 工具箱 / 协会 / 学会 / 36氪 等），实测漏网域持续增补 |
| 出海中介服务商 | 货代 / 物流 / 船务 / 报关 / 货运 / 仓储 / 快递 / 代运营 / 客服外包 / 呼叫中心 |
| 无出海业务的国内公司 | 无出海证据 → 培育池 |
| 外企（无中国证据） | 默认排除 |

黑名单是**运营资产**：巡检与验收发现漏网即增补；入库前拦截与存量兜底两处同源维护。

### 2.3 资格层 · ICP 资格门（五态）

资格是硬性准入，不是评分软加权。先过买家门，再看 CN × 出海：

| icp_status | 判定 | 动作 |
|---|---|---|
| `qualified` | CN 证据 + 出海证据 | 进销售池与今日商机 |
| `cn_domestic` | CN 证据、未见出海 | 培育池，富化后可升级 |
| `foreign` | 有评估结论但无 CN 证据 | 默认排除（`icp=all` 可显式看） |
| `non_buyer` | 买家黑名单命中 | 默认排除；**优先于** CN/出海判定——媒体站哪怕 CN+出海全占也不进池 |
| `unknown` | 证据不足 | 留池待验证，不做有罪推定 |

- **买家门**：域名黑名单 ∪ 名称词表任一命中即 non_buyer；两者都无命中则判不了、不算。
- **CN 证据**（任一）：is_cn（中国招聘站来源 / CSV 中国种子 / meta_ads 中文页名 / 官网中文 ≥30% / ICP 备案号）｜country=CN｜+86 号码。分 **strong**（country=CN、+86、中国招聘站来源、人工·种子录入）与 **weak**（仅 CJK 启发式，是东南亚华人企业误判的主要入口）——weak 不拒之门外但必须可见：详情页打「CN 待核验」，质检 overseas 维优先抽检。
- **出海证据**（任一）：overseas_signals 非空｜fb_whatsapp｜target_countries 非空｜在招海外语义岗（wa_ops / overseas_cs / overseas_sales / social_ops；crm_ops 不算）。
- **「有评估结论」**：富化过，或 meta_ads 来源且有官网——评估过才有资格 foreign，否则保持 unknown 保留翻案通道。
- **排除面（7 处全收敛）**：列表默认、CSV 导出、今日商机、预警、质检、全库富化、自动分配。
- **四行业归类是展示标签不是硬门**（行业常缺失，硬门杀召回）。

### 2.4 价值层 · 靶心

资格层回答「配不配进池」，价值层回答「多值得马上卖」：**靶心 = 已在用 WhatsApp 承接客户**，其证据即意向分主信号（官网 WA 入口、WA 号码多分线、CTWA、在招 WA 运营岗、已用其他 BSP）。出海但 WA 使用未证实 → 低分培育，不驱逐。

## 3. 硬约束

1. **纯免费**：全链路零付费 API、零采购；企查查类数据 API 与联系人供应商采购**永久移除**（非推迟）。
2. **LLM 可空**：无 key 全部降级规则模板并标记来源；免费 LLM 走本机 Ollama。
3. **单进程任务系统**：DB 即队列，多 worker 禁用，调度仅单进程。
4. **礼貌采集**：目标站节流（主页探测 ≥1.5s、翻页 ≥0.5s、官网发现 3s、招聘站 5s+退避）；按分级窗口增量重爬；终态线索退出重爬。
5. **合规**：只采企业公开信息；LinkedIn / Google Maps 不自爬；联系人不做未授权批量获取。
6. **去重键终态**：domain > tel > namecity 三身份列（统一社会信用代码方案已废弃）。

## 4. 主链路

```
meta_ads（主通道：在投广告 + 主页探测 WA）──┐
web_search（免费搜索：企业官网种子）          ├→ 草稿 → 归一化 → 三身份列反查 → 新建/合并线索
job_posting（中国招聘站：默认巡检只补信号）    │
career_site（巡检库内线索的官网招聘页）      ─┘
website_enrich（富化：官网发现 → 抓取检测 → 改存量线索，不走草稿）
手工录入 / CSV 导入（同走去重合并）
                    ↓
ICP 资格门 → 意向分（14 信号）→ 三问 → 今日商机（三问齐备才入批）
                    ↓
        领取 → 跟进建联 → 成交回传（won）
```

- 评分 / ICP / 出海业务类型**同点派生**：合并、富化、联系人变更、手工编辑均触发重评。
- 发现类任务成功 → **自动接力**一次全库富化（种子要靠富化才有信号、才能过门）。

## 5. 功能需求

### FR-1 采集器（5 个）

统一契约：经任务上下文产出草稿落库；参数表单按参数模式动态渲染；站点 / 引擎可扩展（新增不改架构）。

| 采集器 | 定位 |
|---|---|
| meta_ads | **主通道**：挖在投海外广告的中国企业 |
| web_search | 免费搜索：只收企业官网种子 |
| job_posting | 中国招聘站信号巡检（默认不发现新线索） |
| career_site | 巡检库内线索的官网招聘页 |
| website_enrich | 富化（非数据源）：官网发现 + 抓取检测，改存量线索 |

#### FR-1.1 meta_ads

- Meta 官方广告资料库 API（免费 token），按「关键词 × 投放国」搜**在投**广告（每词默认 2 页 × 100）；按广告主页聚合：页名 / 链接 / 广告数 / 文案样本 / 最近投放时间 / 累计广告数。
- **主页探测**（默认开，代理优先 + 直连兜底）：WA 号码（wa.me / api.whatsapp.com / web.whatsapp.com/send）→ fb_whatsapp 证据；公开邮箱（埋点黑名单防误判）；外链官网（解跳转、滤平台域）；中文特征 → is_cn。
- **只收企业**：主页类目命中非企业黑名单（公众人物 / 自媒体 / 媒体 / 政府 / 学校 等，中英）跳过；拿不到类目保守放行；企业类目映射中文行业。
- **CTWA 口径**：API 不暴露广告 CTA；「主页挂 WA + 持续在投」= 已用 WA 做私域获客的代理信号。
- token 缺失 → 任务 failed 带免费申请指引（§9）；无效 → 不产出空结果假成功。
- 默认关键词 = 跨境大卖品类词；默认投放国 = WA 高渗透市场（东南亚 + 中东 8 国）；多国记第一个投放国。

#### FR-1.2 web_search

- DDG 默认（零 key）→ 失败自动降级必应中国；可选 searxng / google_cse / bing。
- 只收企业官网种子：平台 / 社媒 / 门户黑名单（与买家门同源，入库前拦截）+ 内容页过滤（文章 / 词典 / 释义页特征与聚合分隔符启发）+ 泛标题丢弃 + 同域去重 + 归一根 URL。
- 标中国企业 = 双条件：is_cn 参数开 ∧ 标题含 CJK。
- 默认关键词 = 中文长尾业务词（品类词与 whatsapp 单词已被实测否决——结果全是词典 / 文章 / 下载页）。

#### FR-1.3 job_posting

- 站点：jobui / 猎聘 / 前程无忧已接入；BOSS 直聘 / 智联为 STUB（验证码拦截，接入归 V1.5）；站点经参数选择。
- **巡检模式（默认）**：只给库内公司补信号——公司名 + 城市三身份列反查，命中才合并重评分，不中不建行；发现模式开关默认关（招聘数据的价值是**信号**不是公司发现）。
- 产出：is_cn + country=CN；岗位分类五类（wa_ops / overseas_cs / social_ops / crm_ops / overseas_sales）入证据链；`whatsapp_job` 只在 wa_ops 命中置位（同一事实只计一次）。
- 默认关键词 = 中文岗位词组合（站内搜索不吃英文词，单词被模糊匹配稀释）。

#### FR-1.4 career_site

- 巡检库内线索的官网招聘页（官网栏目 + Moka / 北森 / 51job 子域等 ATS 域），一手在招岗位 → 信号合并回原线索；**不产生新线索**，不进自动接力。
- 链路：首页 → 招聘链接（锚文本 / URL 中英词）→ 常见路径兜底 → 薄壳 SPA 渲染 → 分类器即过滤器（不命中词表不算岗位）。
- 证据置信 90（一手招聘页 > 平台列表 85）；轮换巡检，按分倒序每轮默认 20。

#### FR-1.5 website_enrich（富化，非数据源）

**改存量线索、不产生新线索；不出现在数据源列表与任务创建对话框。**

**范围**：列表勾选（指定 ID，不受窗口限制）/ 全库扫描（有网站 ∧ 窗口内未成功富化 ∧ 非终态）。窗口：S 1 天 / A 3 天 / B 7 天 / C 30 天。

**官网发现**（全库扫描前置）：无官网且非 foreign → 公司名搜官网 → 写 website + domain（置信 60）→ 本轮直接富化。每轮上限 30、3s 间隔；失败 / 撞域负缓存 7 天；写前必查 domain 持有者（防重复线索）。

**抓取（四层递进）**：双通道 HTTP（代理优先 + 直连兜底）→ TLS 指纹伪装 → 无头浏览器渲染（未装可选依赖静默降级）。内页 ≤3、**联系类页优先于产品类**，与首页同等待遇。

**检测（联系方式是第一产出）**：

- WhatsApp：wa.me / api.whatsapp.com / web.whatsapp.com/send + 插件特征（joinchat / getbutton / chaty 等）；收集页面全部号码（多分线 = 规模化承接证据）。
- 邮箱：首页 + 内页全扫，mailto 优先，埋点黑名单防误判。
- 电话：明文国际 / 400 热线 / 国内座机 / 中国手机，libphonenumber 口径校验归一 E.164。
- JSON-LD（schema.org Organization）结构化声明**优先于**正则启发。
- 地址尽力而为；社媒 5 平台；场景与 SaaS 信号 8 类（含 wa_bsp 竞品栈 18 品牌、brand_stack 通用栈 13 词，raw HTML 指纹），union 单调合并。
- 基础画像补全：country 只认 CN 硬证据（§2.3 strong 口径）；industry 回填中文标签。

**产出动作**：邮箱 → 「待补全」联系人；WA 号码前 3 → 电话联系人；具名联系人见 FR-5。`enriched_at` 只在成功抓到首页时写；失败原因落线索级标记（详情页可见、成功自愈）。**负证据闭环**：复查未复现已记录的 WA 入口 → `whatsapp_gone` 事件（不翻历史布尔）；证据展示「N 天未复现」（≥90 天标注）。官网归属校验见 FR-5。结束日志「成功 X / 失败 Y」+ 失败站点分层原因。

### FR-2 去重合并（系统的心脏）

1. **归一化**：电话 → E.164（来源国兜底，失败不参与去重）；URL → 可注册域；公司名 → 小写去标点剥法律后缀。
2. **主键优先级**：domain > tel > namecity（归一名+城市）> raw 兜底，宁漏勿重。
3. **三身份列 OR 反查**合并到最早行（存量电话键 + 新数据域名键是常态）；合并后主键收敛 domain；`create_if_missing` = 巡检开关。
4. **合并语义**：标量补空；布尔 OR（`whatsapp_job` 语义自愈——无 wa_ops 证据则重置）；job_urls / 社媒并集；最近投放 / 广告数取 max；来源按（线索, 来源）唯一 touch；自动生成联系人（manual 除外）；重评分。
5. **domain 唯一性由数据库约束兜底**——并发、发现链、合并补全三条撞域路径都不产生重复。
6. **口径迁移**：评分 / ICP / 出海类型规则变更后，全库重评走与采集器同一函数（单一口径）。

### FR-3 意向分（加分制，唯一主分）

分数含义：**「这家公司现在有多需要你」——用 WA 承接客户的证据强度为主，出海规模与 SaaS 买入为辅**；不是企业质量分。命中分值相加、封顶 100；无并存口径、无权重维度（加权模型待成交数据回传后）。

分级：**S 80–100 立即跟进｜A 60–79 高潜力｜B 40–59 培育池｜C 0–39**

| # | 信号 | 检测来源 | 分值 |
|---|---|---|---|
| 1 | `ctwa_ad` CTWA 私域获客 | meta_ads 主页探测 | +40 |
| 2 | `wa_ops_job` 在招 WA 运营岗 | 招聘 | +30 |
| 3 | `wa_bsp_competitor` 已用其他 WA SaaS（替换商机） | 富化竞品栈 | +30 |
| 4 | `site_whatsapp` 官网 WA 入口 | 富化 | +25 |
| 5 | `overseas_cs_job` 在招海外/英文客服岗 | 招聘 | +20 |
| 6 | `wa_business` WA Business 业务号 | 富化文本自述 | +15 |
| 7 | `meta_ads_running` 在投 Meta 海外广告 | meta_ads 来源 | +15 |
| 8 | `overseas_biz` 出海业务证据 | 富化 | +15 |
| 9 | `saas_buying` SaaS 买入成规模（强度 ≥40，扣 wa_bsp 防双计） | 富化强度表 | +15 |
| 10 | `overseas_site` 海外独立站 | 富化 | +10 |
| 11 | `crm_job` 在招 CRM/客服系统运营岗 | 招聘 | +10 |
| 12 | `three_markets` 覆盖 ≥3 国市场（投放国 ∪ 官网提及） | meta_ads + 富化 | +10 |
| 13 | `multi_numbers` 多 WA 分线（≥2 号码） | 富化号码收集 | +10 |

**互斥与防双计**：CTWA(+40) 替代在投(+15)；fb_whatsapp 单独存在不给分；saas_buying 扣 wa_bsp 类目分；`whatsapp_job` 列与 wa_ops 同一事实只计一次。SaaS 类目与规模信号（岗位数 / 社媒广度 / 联系人数 / 来源数 / 广告量）不进主分。

**锚点案例（校准基线）**：CTWA 跨境电商 85/S｜竞品迁移型 70/A｜官网私域 DTC 65/A｜WA 运营在招中型 55/B｜出海无 WA 的工厂 25/C。

**落库与派生**：命中键 → 分值映射 + 明细 items（可解释「这分怎么来的」）；等级为真实列可筛选。评分写回时同点派生 icp_status（§2.3）与出海业务类型四形态（跨境电商 / 品牌出海 / 出海服务 / 出海营销；无证据不硬分类）。

**产品推荐（对齐 §0 可售产品）**：WA 消息线 4 规则（客服 SaaS / 营销消息 / 交易通知 / AI 智能客服）+ 出海 SaaS 线（信号 ≥2 类或买入强度 ≥40）+ 广告代理延伸线（在投 Meta 广告 → 开户/优化/返点，与 WA 使用无关）。**需求类型 A–F**：A 消息 / B API 升级 / C 客服 / D 营销 / E 私域 / F 广告投放。「是否用 WA」的判定必须含 WA 号码列表（官网无入口 + 主页多号码 + fb_whatsapp 的 CTWA 大卖是真实形态）。

### FR-4 三问生成器

- **why 为什么需要你**：意向分明细 top-3（中文标签 + 分值 + 证据 URL，可点开核对）。
- **what 应该卖什么**：需求类型 + 推荐产品 + 切入场景 + SaaS 信号标签（wa_bsp 标「在用」——在用什么就知道该替换/集成什么）。
- **who 应该找谁**，两档永不空：
  - 一档·真实建联入口：联系人（tier1 决策层 > tier2 > tier3，前 3）/ WA 号码（前 3）/ 官网 WA 入口；
  - 二档·目标角色（无联系人时按信号派生，带「去哪找」提示）：wa_ops → WA/私域运营负责人｜overseas_cs → 海外客服负责人｜CRM 类信号 → CRM/客服系统负责人｜fb_whatsapp → 海外营销负责人｜兜底 → 海外业务负责人。
- **齐备 = why ≥2 条证据 ∧ what ≥1 个推荐产品 ∧ 真实建联入口任一**；目标角色只是方向提示，不算建联入口。齐备是今日商机的入选门槛。

### FR-5 可行动底线（线索价值 = 拿到就能行动）

不满足底线的线索不进销售视野：错配数据被清除；无联系方式的线索因三问不齐备进不了今日商机。

1. **官网必须真是这家公司的**：两证齐全才判错（页面标题含知名平台干扰词 ∧ 公司名主词不在标题；只有名称零重叠而无干扰词 = 存疑放行，品牌名与注册名不一致是常态）。判错 → **连坐清除**：官网 / 域名 / 邮箱 / 电话 / WA 入口与号码 / 全部信号 / 富化自动联系人全清（错站数据全是别人的）+ 重评分 + 记因，线索回到无官网状态等官网发现重找。
2. **至少一条可行动联系方式**（电话 / 400 / WA / 邮箱）：检测覆盖明文国际、400 热线、国内座机、中国手机（「只认国际前缀」已废除）；电话选取定序 **座机总机 > 国际号码 > 400 热线 > 手机**（先抓到的可能是招商热线而非对外联系电话；手机归具名联系人）。
3. **具名联系人 = 「找谁」的最优答案**：识别「部门 联系人：姓名（职务）联系电话：手机」形态 → 联系人记录；职务分层（负责人/总监/总经理/创始人/CEO → tier1，经理/主管/部长 → tier2）；置信 88；单次新增 ≤6。

### FR-6 今日商机与销售闭环

- **今日商机批次** = 今日新晋 S/A（等级变更事件）+ 今日新增高分（qualified 且 ≥60）+ 今日高价值预警切片；**三问齐备才入批**（FR-4）；质量门槛内**不设数量上限**；行内呈现三问；空态给根因诊断（meta_ads token / 调度开关 / qualified 数）。
- **领取（claim）**：销售自助认领，无需主管权限；原子抢占并发安全（两人同时领取恰好一个成功）；他人已持有 → 撞单报错；自己持有幂等。入口：列表行 / 今日商机页 / 详情页头部。
- **分配**：主管指派 / 释放 / 自动分配（共享池按分数轮转 + 负载上限），需分配权限。
- **跟进状态机（10 态）**：`unassigned` 未分配（NULL 同义）/ `pending` / `contacted` / `replied` / `opportunity` / `quote` / `negotiation` / **`won` 成交回传** / **`invalid` 无效（终态）** / `paused`。一次跟进一条不可变历史；won / invalid 终态退出富化范围。
- **预警中心**：高价值预警事件 → 站内中心 + 今日商机切片，均过 ICP 门。
- **AI 分析 + 话术**：LLM 缺省降级规则模板，标记生成来源。
- **数据源管理**：渠道 × 等级产出 + 各采集器爬取逻辑说明。

### FR-7 质量抽检

- 三维度（WhatsApp / 出海 / 联系人）；随机取样、已标不重复出队、带核验证据；overseas 维弱 CN 证据优先出队，contact 池含电话联系人。
- 标注 正确 / 错误 / 拿不准；每线索取最新标注，拿不准不进准确率分母。
- 看板：三准确率 vs 目标线 90% / 80% / 60% + S+A 占比 vs 20% + 覆盖进度。

### FR-8 任务系统与自动接力

- 状态机 pending → queued → running → completed / failed / cancelled；排队中可直接取消、运行中逐条响应；**进程重启把 running 置 failed**。
- DB 即队列，默认并发 2；闸门满 = 排队等待（cron 触发**排队不失败**）；进度 5s 节流写库；超时可配；cron 存库重启自动恢复、仅单进程调度。
- **自动接力**：发现类任务（web_search / job_posting / meta_ads）成功完成 → 自动排入隐式全库富化；默认开；去重只认「已有全库富化在排队中」（不看时间窗——窗口节流会整批漏掉新增线索）；失败任务不接力；接力写原任务日志。

### FR-9 权限与数据可见性

- 三层：线索 / 跟进 / 查看 = 登录用户；任务管控（建/改/删/执行/取消）+ 删线索 = 超级管理员；分配族 + 数据源管理 = 权限码（sales_manager 角色可用）。
- 权限码词表 7 个（lead:read/write/delete、assign:lead、task:manage、user:manage、stats:read）——V1 实际接线 assign:lead 与 stats:read，余为扩展预留。
- 数据权限三级（all / team / own）：列表 / 导出 / 详情 / 事件 / 联系人 / 跟进 / 今日商机 / 销售域强制过滤；统计与趋势为全局口径。

### FR-10 数据进出

- 手工录入：走同一去重合并；manual 来源不自动生成联系人。
- CSV 种子导入：≤5000 行，走 upsert；中国种子可标 CN 证据。
- CSV 导出：当前筛选口径、字段可选、≤5 万行、UTF-8 BOM、按分数倒序。
- 新环境初始化：leads 表为空时一次性导入业务种子（线索 + 三类定时任务），默认开、测试环境强制关。

## 6. 非目标

- **V1 不做**：复杂 CRM、自动发送 WhatsApp、AI Agent、复杂 BI（销售漏斗 / 排行榜 / 自然语言搜索——已移除，不再恢复）。
- **永久不做**：企查查类数据 API、联系人供应商采购（§3 纯免费）；LinkedIn / Google Maps 自爬；加权多维评分模型（成交数据回传前）；统一社会信用代码去重。

## 7. 指标

- **数据质量**（质检度量）：WhatsApp 识别 ≥90%｜出海识别 ≥80%｜联系人有效率 ≥60%｜S+A 占比 ≥20%。
- **业务指标**（方向性，待销售运营回传后度量）：线索→联系率 ≥30%｜→有效商机率 ≥10%｜人均有效线索 ≥100/月｜找客户时间 ↓70%。
- **里程碑**：1 万家中国出海企业种子 → 筛出 500–1000 个 S/A 即模型验证成立 → 逐级放大。

## 9. 运营依赖（系统外、只有运营侧能做）

1. **申请 META_ADS_ACCESS_TOKEN**（免费：facebook.com/ads/archive/api）——**唯一 S/A 制造机**（CTWA +40 / 在投 +15 / 投放国计数都来自它），未配置时今日商机结构性缺 S/A，属预期。
2. **开启调度**并配置三类定时任务（meta_ads / 招聘巡检 / 全库富化）——「每天收到一批」依赖调度自动跑。
3. **质检持续标注**——三准确率与 S+A 占比指标的可信前提。
4. **词表运营**——买家黑名单 / 搜索关键词 / 岗位词表按漏网案例增补（两处同源维护）。
5. **跑通后人工核 50–100 条三问齐备的 S/A**（验收动作）。

- **冻结语义**：V1 = 定稿日已实现并通过测试的能力（含当日工作区在途改动），零欠账。
